# Tanuki Flow

Интерактивный демонстрационный прототип Тануки для проверки пользовательских сценариев.

**Открыть прототип:** https://andreykalimulin.github.io/tanuki-flow/

Дополнительная действующая ссылка на Yandex Cloud: https://tanuki-flow-cursor-20261028.website.yandexcloud.net/

## Что работает

- Главная, каталог Тануки, поиск, акции и сторис.
- Доставка и самовывоз, добавление и удаление товаров, количество и пересчёт сумм.
- Выбор времени, оформление, имитация статусов и отмена заказа.
- Указатель для демонстрации кликов мышью и адаптация к высоте браузера.

Оформление, оплата и статусы имитируются. Реальные заказы и платежи не отправляются. Прототип не собирает результаты прохождения и не подключает аналитику.

## Публикация

GitHub Pages публикует содержимое корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Ресурсы и шрифты находятся в этом репозитории; сайт не зависит от Яндекса.

Выложена версия от 28 октября 2026 года без изменений интерфейса и логики. Для обновления замените файлы готового сайта в корне репозитория, сохранив `.nojekyll` и этот README.
